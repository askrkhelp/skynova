# SkyNova Fare Rules — FLEX

The Flex fare is our most popular fare. It balances price and flexibility.

| Rule | Flex |
|------|------|
| Refundable | Yes — refundable up to 2 hours before departure, minus a ₹1,500 cancellation fee |
| Change / reschedule | One free date/flight change; each additional change is ₹1,500 + fare difference |
| Cancellation window | Up to 2 hours before scheduled departure for a refund |
| Check-in baggage | 25 kg |
| Cabin baggage | 7 kg, 1 piece |
| Seat selection | Free standard seat selection |
| Meal | One meal included |
| Priority / lounge | Not included |

**Key point for support:** a Flex ticket **is refundable** (minus ₹1,500) if cancelled at least 2 hours before departure. It also includes **one free change**.
