# SkyNova Fare Rules — SAVER

The Saver fare is our lowest-priced fare. It trades flexibility for price.

| Rule | Saver |
|------|-------|
| Refundable | No — only statutory taxes are refunded on cancellation |
| Change / reschedule | Allowed for a fee of ₹3,000 per passenger per sector + any fare difference |
| Cancellation window | Cancel any time before departure (only taxes returned) |
| Check-in baggage | 15 kg |
| Cabin baggage | 7 kg, 1 piece |
| Seat selection | Paid (chargeable) |
| Meal | Not included (buy on board or pre-book) |
| Priority / lounge | Not included |

**Key point for support:** a Saver ticket is **non-refundable**. If a customer cancels a Saver fare voluntarily, only the statutory taxes are refunded — not the base fare. The 24-hour free-cancellation rule (see refund policy) still applies if booked 7+ days before departure.
